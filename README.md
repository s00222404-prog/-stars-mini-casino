# STAR PLAY — C++ prototype

A Raylib C++17 mini-game prototype with animated glass-style UI and three demo games: basketball, bowling, and dice.

## Status
The project is currently being built. This repository uses demo points only; no Telegram Stars payments or real-world prize payouts are implemented.

## Build requirements
- C++17 compiler
- Raylib 5.x
- CMake 3.16+

## Build
```bash
cmake -S . -B build
cmake --build build
```

See the source files and project instructions as they are added.
